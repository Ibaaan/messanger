# Messanger

[English](README.md) | [Русский](README.ru.md)

## О проекте

Messanger — браузерный текстовый мессенджер, позволяющий пользователям регистрироваться, находить других пользователей, создавать групповые чаты, обмениваться сообщениями в реальном времени и просматривать историю переписки.

## Возможности

- Регистрация, вход в аккаунт и сохранение сеанса между посещениями.
- Смена пароля и выход из аккаунта.
- Поиск пользователей и создание групповых чатов.
- Отправка и получение текстовых сообщений в реальном времени.
- Просмотр истории переписки и загрузка более ранних сообщений.
- Отображение количества непрочитанных сообщений и синхронизация статусов прочтения между вкладками браузера.

## Как запустить

### Локальный запуск (Bash)

Для локального запуска потребуются .NET 10 SDK, Docker с поддержкой Compose и OpenSSL. Все команды необходимо выполнять в Bash из корневого каталога проекта.

1. Настройте и запустите PostgreSQL:

   ```bash
   cp .env.example .env
   docker compose up -d --wait
   ```

2. Создайте локальный закрытый ключ для подписи токенов:

   ```bash
   mkdir -p .local
   openssl genpkey -algorithm RSA \
     -pkeyopt rsa_keygen_bits:2048 \
     -out .local/jwt-private.pem
   ```

3. Настройте переменные окружения в текущем терминале:

   ```bash
   export ConnectionStrings__Postgres="Host=localhost;Port=5432;Database=messanger;Username=messanger;Password=messanger_local_only"
   export Jwt__PrivateKeyPath="$PWD/.local/jwt-private.pem"
   ```

   Если вы изменили учётные данные базы данных или порт в файле `.env`, внесите соответствующие изменения в строку подключения.

4. Настройте HTTPS, примените миграции базы данных и запустите приложение:

   ```bash
   dotnet dev-certs https --trust
   dotnet run --project Messanger -- --migrate
   dotnet run --project Messanger --launch-profile Local
   ```

   В Linux в зависимости от дистрибутива и браузера может потребоваться дополнительная настройка доверия к сертификату.

После запуска приложение будет доступно по адресу [https://localhost:7100](https://localhost:7100).

## Безопасность

- Пароли хранятся в виде хешей с использованием соли.
- Для управления сеансами используются токены доступа с коротким сроком действия и токены обновления с механизмом ротации.
- При смене пароля существующие сеансы завершаются, а связанные с ними активные соединения закрываются.
- Доступ к чатам и сообщениям контролируется с учётом участия пользователей в чатах и их ролей.
- Для защиты соединений и операций с сеансами используются HTTPS, защита от CSRF и ограничения на допустимые источники браузерных запросов.
- Ограничение частоты запросов и количества одновременных соединений помогает предотвращать злоупотребления.
